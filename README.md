# Dasabami — website

Static, dependency-free site for Dasabami (დასაბამი), the family qvevri wine cellar of Zaza Darsavelidze in Tamarisi, Kvemo Kartli, Georgia.

## Structure

```
index.html            English page and single source of truth: hero, story, wines, tech specs, qvevri, press, gallery, find, FAQ, contact
ka/index.html         Georgian page    (generated by build.py, do not edit by hand)
ja/index.html         Japanese page    (generated)
es/index.html         Spanish page     (generated)
fr/index.html         French page      (generated)
wines/                wine pages: /wines/ (all wines) and /wines/<grape>/ (generated by build_wines.py)
<lang>/wines/         the same wine pages in ka, ja, es, fr (generated)
build.py              regenerates the SEO head, JSON-LD and i18n data in index.html and writes the four language pages, then the wine pages
build_wines.py        wine pages and sitemap.xml: page template, per-wine JSON-LD (Product, BreadcrumbList, FAQPage), tech specs
i18n/en.json          English meta, JSON-LD text and FAQ
i18n/ka|ja|es|fr.json translations: meta, JSON-LD text, FAQ, cellar-guide texts (js) and every page string (strings)
i18n/_strings.en.json list of all English strings on the page (the keys for "strings")
i18n/wines.<lang>.json wine-page copy per language (same structure in every language; a language gets wine pages once its file exists)
404.html              not-found page
assets/css/style.css  design system (glass, motion, dark mode)
assets/js/main.js     scroll motion, wine filter/sheet, quotes, lightbox, countdown, cellar guide
assets/js/wine.js     small script for the wine pages (reveal, nav, language menu, copy address)
assets/img/           WebP photos, -sm (800px) and -lg (up to 1600px)
assets/brand/         favicon, app icons, logo, Open Graph share image
robots.txt            allows search engines and AI crawlers, points to the sitemap
sitemap.xml           every page in every language with hreflang alternates, plus image sitemap (generated)
llms.txt              short fact sheet for AI assistants (llmstxt.org format)
llms-full.txt         complete plain-text fact sheet for AI assistants
site.webmanifest      app manifest
```

## Languages

After editing `index.html` or any `i18n/*.json`, run:

```bash
python3 build.py
```

It rewrites the SEO block, JSON-LD and i18n script in `index.html` and regenerates `ka/`, `ja/`, `es/` and `fr/`, then prints how many strings each language keeps in English. Strings are matched by their exact English text (whitespace collapsed), so if you change English copy, regenerate `i18n/_strings.en.json` and add the new key to each language file; untranslated strings fall back to English. The site URL is the `SITE` constant at the top of `build.py`.

## Run locally

```bash
python3 -m http.server 4317
```

Then open http://localhost:4317.

## SEO / GEO

- JSON-LD in every language page (localized names, descriptions and FAQ): WebSite, WebPage, Winery/Organization, Person (Zaza), OfferCatalog of wines with tech specs, Event (Amber Georgia Berlin), FAQPage.
- One page per wine in every language (`/wines/rkatsiteli/`, `/ka/wines/rkatsiteli/` …) with its own title, description, canonical, hreflang, breadcrumbs, Product and FAQPage JSON-LD. Wine copy and FAQ live in `i18n/wines.<lang>.json`; tech specs live in `build_wines.py`.
- Open Graph and Twitter cards with `assets/brand/og-image.jpg` (1200×630).
- Visible FAQ and an “at a glance” fact list mirror the structured data, so search engines and AI answers get the same facts.
- `robots.txt` explicitly allows AI search crawlers; `llms.txt` and `llms-full.txt` summarize the facts.

### Site URL

All absolute URLs use `https://dasabami.co/` (`SITE` in `build.py`, plus `sitemap.xml`, `robots.txt`, `llms.txt` and `llms-full.txt`). To move to another domain later, replace it everywhere and rebuild:

```bash
grep -rl "https://dasabami.co/" --exclude-dir=.git . | xargs sed -i '' "s#https://dasabami.co/#https://NEW-DOMAIN/#g" && python3 build.py
```
